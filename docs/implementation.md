# Monitor 实现与验收

自研的只读服务器探针。核心为 Rust Agent、Rust/Axum Hub、SQLite、React 管理后台与默认公开主题。

## 必须完成的能力

- 节点新增、编辑、排序、隐藏、删除、Token 换发和安装命令。
- Agent 主动 WSS 连接；基础信息、CPU/内存/磁盘/网络/连接数、PSI、重连与心跳。默认不接受远程执行。
- 分钟历史、小时汇总、保留期；内核计数器与 boot_id 的累计流量、日/月周期、额度预测。
- TCP、DNS、TLS、HTTP 分段探测，IPv4/IPv6、动态任务与网络画像。
- 故障事件、异常前后回放、断联补传、多节点探测关联、脱敏诊断导出。
- 密码登录、可注销会话、登录限流、私有站点与服务端公开字段白名单。
- 离线/恢复、流量、到期通知，Telegram/Webhook、宽限和去重。
- 内置后台、默认主题、主题安装/切换/配置；Komari 公开 REST/RPC/WebSocket 适配与 monitor 主题适配。
- 数据备份/恢复、Linux systemd 安装/卸载、Dockerfile、构建与运行说明。
- 有意义的协议/计数器/隐私/鉴权/探测/归档测试；真实 Hub + Agent 接入和浏览器端到端验证。

## 设计约束

- Agent 没有 Shell、远程终端或自更新；远程任务只有预定义网络探测，数量、间隔和时限受限。
- 原生接口固定在 `/api/v1`。现有主题的相同旧路径根据当前主题 profile 输出，内部模型保持一致。
- 管理后台固定 `/admin`，主题仅替换公开页。ZIP/tar 导入必须限制解压大小并拒绝路径穿越与链接。
- 公开状态直接在服务端过滤凭证、地址、主机名、私有备注和原始计数器。
- 本地演示数据仅在显式 `--demo` 下生成，页面始终标记演示。正式模式不伪造遥测。
- 内存回放可以补偿 Agent 存活期间的断联，重启或断电会丢失内存窗口；界面显示采样覆盖率。
- 相关性结果是候选原因，不宣称已证明根因。单 Hub 无法在自身停机时发送通知。
